# Курсовая работа. Создание персонального сайта с использованием MkDocs

## Цель работы

Создать персональный сайт на генераторе статических сайтов MkDocs с темой Material, наполнить его содержанием на языке разметки Markdown, настроить внешний вид и проверить работу локально.

## Используемые технологии

- **MkDocs 1.6.1** — генератор статических сайтов. Превращает файлы Markdown в готовый набор HTML-страниц.
- **Material for MkDocs 9.7.7** — тема оформления. Даёт навигацию, поиск, тёмную тему, карточки и иконки.
- **Markdown** — язык разметки, на котором написано всё содержание страниц.
- **Python 3.12.9** — среда, в которой работает MkDocs.
- **CSS** — собственные стили поверх темы.

### 3. Настройка конфигурации

Файл `mkdocs.yml` — единственное место, где задаются настройки всего сайта.

**Первая часть: название, тема, навигация.**

![Конфигурация: тема и навигация](screenshots/03-mkdocs-theme-nav.png)

Что здесь важно:

- `site_name`, `site_description`, `site_author`, `site_url` — название сайта, описание для поисковиков, автор и будущий адрес публикации;
- `theme: name: material` — подключение темы, `language: ru` переводит её интерфейс на русский;
- `logo` и `favicon` — свой знак в шапке и значок во вкладке браузера;
- `palette` — две цветовые схемы: светлая `default` и тёмная `slate`, обе с розовым как основным и акцентным цветом. Блок `toggle` создаёт переключатель в шапке;
- `features` — возможности темы: `navigation.tabs` выводит разделы вкладками в шапке, `navigation.top` добавляет кнопку возврата наверх, `search.highlight` подсвечивает найденное;
- `nav` — порядок страниц в меню. Без этого блока MkDocs выстроил бы страницы по алфавиту;
- `extra_css` — подключение собственного файла стилей.

**Вторая часть: расширения Markdown, плагины, футер.**

![Конфигурация: расширения и футер](screenshots/04-mkdocs-extensions.png)

- `markdown_extensions` — дополнительные возможности разметки. `attr_list` и `md_in_html` нужны для карточек, `tables` для таблиц, `admonition` для блоков-подсказок, `pymdownx.emoji` подключает набор иконок Material;
- `plugins: search` с `lang: ru` — поиск по сайту с поддержкой русской морфологии;
- `extra: social` — ссылки на GitHub, Telegram и почту, выводятся иконками в футере;
- `copyright` — строка копирайта внизу каждой страницы.

### 5. Стилизация

Помимо настроек темы в `mkdocs.yml` написан собственный файл стилей `docs/stylesheets/extra.css`. В нём:

- малиновая палитра, заданная переменными и применённая к обеим цветовым схемам;
- оформление шапки главной страницы: градиентный фон, круглая фотография с обводкой, имя с градиентной заливкой текста;
- карточки: скругления, рамка, подъём и подсветка при наведении курсора;
- теги технологий на странице проектов в виде розовых капсул;
- раскладка карточек: четыре в ряд на главной, одна широкая на странице проектов;
- оформление таблиц, кнопок и цитат;
- правила для узких экранов: на телефоне шапка перестраивается в один столбец.

Тёмная тема включается кнопкой в шапке. Цвета для неё заданы отдельно, чтобы малиновый не был слишком ярким на тёмном фоне.

### 6. Тестирование и сборка

**Поиск.** По запросу `nb` найдено 5 совпадений на трёх страницах, найденное подсвечено в результатах.

![Проверка поиска](screenshots/16-search.png)

**Локальный сервер.**

```bash
mkdocs serve
```

```
INFO - Building documentation...
INFO - Documentation built in 0.13 seconds
INFO - Watching paths for changes: 'docs', 'mkdocs.yml'
INFO - Serving on http://127.0.0.1:8000/devops-lab-presnyakova/
```

Сервер следит за папкой `docs` и файлом `mkdocs.yml`: при сохранении любого файла сайт пересобирается, а страница в браузере обновляется сама. Адрес содержит `/devops-lab-presnyakova/`, потому что в `site_url` указан будущий адрес публикации на GitHub Pages.

![Запуск локального сервера](screenshots/17-mkdocs-serve.png)

**Сборка статических файлов.**

```bash
mkdocs build
ls -la site/
```

```
INFO - Cleaning site directory
INFO - Building documentation to directory: /Users/anastasia/devops_labs/coursework/site
INFO - Documentation built in 0.14 seconds
```

В папке `site` появились: `index.html` — главная страница, папки `about`, `projects`, `resume`, `achievements`, `contacts` с HTML-страницами разделов, `assets` со стилями и шрифтами темы, `images` с картинками, `search` с поисковым индексом, `sitemap.xml` для поисковых систем и `404.html` для несуществующих адресов.

Это и есть готовый сайт: обычные файлы, которые можно выложить на любой хостинг, сервер с Python для их работы не нужен.

![Сборка сайта](screenshots/18-mkdocs-build.png)

В выводе обеих команд есть предупреждение от разработчиков темы о будущей версии MkDocs 2.0, в которой изменится система плагинов. На работу текущей версии оно не влияет.

## Выводы

Создан персональный сайт из шести страниц на MkDocs с темой Material. Содержание написано на Markdown, оформление настроено через конфигурацию темы и собственный файл CSS, работа проверена локально и сайт собран в статические файлы.

Что стало понятно на практике:

- содержание отделено от оформления: страницы пишутся простым текстом, а внешний вид задаётся один раз в конфигурации, поэтому добавление новой страницы сводится к созданию файла и строчки в `nav`;
- готовая тема закрывает большую часть задач вёрстки: навигация, адаптивность под телефоны, тёмная тема и поиск работают без единой строки кода;
- собственный CSS позволяет отойти от стандартного вида темы, не отказываясь от неё целиком;
- результат сборки — обычные статические файлы, поэтому сайт можно разместить бесплатно, например на GitHub Pages.
